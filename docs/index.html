⚙️ 设置

仓库（自动识别，一般无需修改）
GitHub Token（用于一键提交爬取任务，仅存本机）
在 GitHub → Settings → Developer settings → Fine-grained tokens 创建：仅授权本仓库，权限 Actions: Read and write 即可。 不填 Token 时，将改用「提 Issue」方式提交任务（需手动点两下）。
首次使用检查清单
  1. 仓库 Settings → Pages → Source 选 Deploy from a branch，分支 master 目录 /docs
  2. Settings → Actions → General → Workflow permissions 选 Read and write
  3. Settings → General → Features 勾选 Issues（免 Token 提交方式需要）
  4. 把本页添加到主屏幕，获得 App 体验
