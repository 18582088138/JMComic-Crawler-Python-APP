设置

仓库（自动识别，一般无需修改） GitHub Token（一键提交爬取任务所需，仅存本机）
点上方按钮打开 GitHub 经典 Token 创建页（已预勾 public_repo 权限）： 拉到底点 Generate token → 复制 ghp_ 开头的字符串 → 粘贴到下面即可。 想要最小权限可改用 Fine-grained token （仅授权本仓库、Actions: Read and write）。 都不填时，爬取将改用「提 Issue」方式提交。
书架保留数量（每个站点）
每站最多保留 超出后书架会提示「下载或清理」；防爆仓硬上限为保留数+10
首次使用检查清单
  1. 仓库 Settings → Pages → Source 选 Deploy from a branch，分支 gh-pages 目录 /(root)
  2. Settings → Actions → General → Workflow permissions 选 Read and write
  3. Settings → General → Features 勾选 Issues（免 Token 提交方式需要）
  4. 把本页添加到主屏幕，获得 App 体验
